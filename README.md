The College Club Management System (CCMS) is a modern, responsive full-stack web application designed to simplify college club management and improve communication between students and club administrators. Built using Node.js, Express.js, MySQL, HTML, CSS, and JavaScript, it allows students to explore clubs, apply for memberships, track application statuses, view announcements, and register for events. Club administrators can manage membership requests, publish announcements, schedule events, and maintain member records, while super administrators have access to all clubs. The system features JWT-based authentication, role-based access control, secure password handling, and a responsive user interface, providing an efficient and user-friendly platform for managing campus activities.
